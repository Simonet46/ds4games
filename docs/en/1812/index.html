How to play

  1. 1

    Roles

    One Author, everyone else is a Reader. Each row has a Captain who decides if there’s no agreement.

  2. 2

    Setup

    Four face-up rows: characters, situations, places and dishes, in 5 or 6 columns depending on the level. The book-box works as a screen.

  3. 3

    The secret code

    The Author rolls the dice inside the box: the color is the row and the number is the column.

  4. 4

    Think in pictures

    The Author takes six Author cards, chooses four and places one next to each row. Water for the washerwoman, a bowl for the locro stew.

  5. 5

    Debate and decide

    The Readers place their pawns, say the code out loud, and the Author hands over the envelope with the number of hits.

  6. 6

    End of the game

    Crack the code before the turns run out and everyone wins. At the end, the Author tells the true story using the four cards.

The rules that make it special

The flag

On levels that allow it, the Author can discard cards and draw back up to six. To announce it, they sing a verse of the national anthem.

Sand timer

For extra pressure, limit how long the Readers can debate.
