The Secrets of the Eiffel Tower

Les Secrets de la Tour Eiffel

How to play

  1. 1

    Setup

    Build a grid of 4 rows by 6 columns: characters, situations, places and dishes. The last person to eat a croissant is the Author.

  2. 2

    The secret code

    Behind the book, the Author rolls the dice. The color gives the row (blue character, red situation, yellow place, green dish) and the number gives the column.

  3. 3

    Clues without words

    The Author draws seven Author cards, chooses four and places one next to each row, all at once.

  4. 4

    Every Reader writes

    In secret, each Reader writes the code they believe is right and hands the sheet to the Author.

  5. 5

    How many, not which

    The Author says out loud how many each Reader got right. If nobody cracked it, four new cards go down next to the previous ones.

  6. 6

    End of the game

    There are up to four rounds. The Reader who cracks the code wins together with the Author. If nobody does, there’s one last chance with no new cards: whoever gets it then wins alone.

The rules that make it special

Sign the box

The winner writes their name and the Author’s inside the box, and the Author tells the true story of Gustave Eiffel.

Ties

The player with the most correct answers over the game wins. If it’s still tied, the victory is shared.

Co-op mode

Everyone on the same team, with one score sheet and four turns to crack the code. From 2 to 10 players: the more of you, the more you talk.

A box that looks like a book

Illustrated cards of Paris, colored dice and a score sheet for every Reader.
